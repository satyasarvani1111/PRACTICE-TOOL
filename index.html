User Guide

Keyboard shortcuts for workstation editing.

Aarohanam / Avarohanam display
1.Enter the full Aarohanam vocabulary.
2.Enter the full Avarohanam vocabulary.
3.Click DISPLAY once to apply both.
4.Notation automatically uses the exact Aarohanam spelling while moving upward and the exact Avarohanam spelling while moving downward.
5.Only notes present in either field are enabled. They work and display across all 3 octaves.
ImportantNo combined labels such as R2 / G1 are used. The note is displayed exactly as written in the selected vocabulary direction.

Top controls & projects
Play / PauseStart or pause notation playback.
StopStop playback and return to the start.
Metronome ♩While notation is playing, adds a beat click to playback. When notation is stopped, click it to play the metronome independently at the selected BPM. Click again to stop.
SoundEnable or mute typing sounds.
BPMUse −10, −1, the value box, +1 or +10. BPM sets the beat duration.
Speed1st = 1 letter/beat, 2nd = 2 letters/beat, 3rd = 4 letters/beat. Speed changes note timing; BPM remains the beat tempo.
ShrutiSet the tonic used for playback.
Count-inChoose the count-in before playback.
Cycle / Jathi / SubdivisionSet the default tala structure, jathi and number of note positions per beat.
Exercise rhythm controlsEach workstation row can have its own Tala (I / O / U pattern), Jathi (3 / 4 / 5 / 7 / 9) and notes-per-beat value (1 to 9). These settings can change between exercises while the BPM stays constant.
Subdivision numbers1 means 1 note position per beat; 2, 3, 4, 5, 6, 7, 8 or 9 means that many note positions inside each beat.
ZoomChange the workstation view from 20% to 150%.
Save / Open / New ProjectSave the complete project and restore it later.
Play Row / Mark Range / Play SelectedUse ▶ Play on an exercise row to play only that row. For several rows or a custom portion, click Mark Range, then click the first box and the ending box. The selected range is highlighted; click Play Selected to play it once, or Loop to repeat it. Dragging across boxes also works.
MP3 / MP4 / PNGExport using the title and current presentation settings. MP3/MP4 use the selected speed and include the speed in the filename.
